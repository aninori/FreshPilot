INPUT

Exception

From the exception checks: product + type. Phantom stock, shrink spike, order swing, low‑confidence match, yield or bake plan change.

RULES

Triage

Runs simulate_order for the base order and loads shelf capacity. Fresh evidence ledger, 30 s deadline, ≤ 8 tool calls; shares the run cost cap.

LLM

Investigate

gpt‑4o‑mini picks which evidence to gather, calls read‑only tools, then must call submit_finding. Proposes an action; never a number of its own.

GATE

Validate

  • Schema + same item
  • calc_id from this run
  • Evidence in tool ledger
  • Every number traced
  • 0.5–1.6× base, ≤ shelf
  • ≤ 60 words, 3 reasons
RULES

Route

Escalate if risk high, confidence low, shelf check or supplier notice, or any guardrail fired. Else auto‑approve.

LLM

Narrate

LLM findings only: plain‑language rewrite, same numbers. Re‑validated; fail → retry once → template. Route recomputed after.

HUMAN

Decision card

Escalated items wait in Decisions: Approve · Adjust · Reject + reason. A shelf check can go to staff; the count re‑runs the engine.
